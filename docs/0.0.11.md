# YourSQL 0.0.11

- 설정에 **하루 목표 사이클**을 추가했습니다. 한 사이클은 기존과 같은 빈칸 6문제와 SQL 작성 2문제이며, 1 이상의 정수로 목표를 정할 수 있습니다.
- 현재 사이클과 하루 목표 진도를 분리해 표시합니다. 목표가 남으면 **다음 사이클 시작**, 목표를 달성하면 **추가 학습하기**로 이어갑니다.
- 목표 변경은 오늘부터 적용됩니다. 완료한 사이클, 진행 중인 배정과 답안, SQL 초안은 유지되며 과거 날짜의 목표와 달성 여부는 바뀌지 않습니다.
- 달력에 날짜별 목표와 완료 사이클을 표시하고, 자유 연습·복습 풀이 수는 목표 사이클 계산에서 제외합니다.
- 복습 알림은 첫 사이클이 아니라 설정한 하루 목표 전체가 완료되는 순간 하루 한 번 표시됩니다.
- 전체 40단원을 마쳐 새로 배정할 문제가 없으면 문제를 자동 반복하지 않고 전체 과정 완료를 안내합니다. 목표량이 남았더라도 실제 완료 사이클만 기록합니다.

## 검증

- 핵심 검사 `npm test`: 51개 통과
- 소스 화면 검사 `npm run test:ui`: 통과
- 2사이클 목표 복습 알림 검사 `npm run test:reminder`: upcoming·due·none 시나리오 통과
- Mac 루트 앱 검사 `npm run test:app`: 통과
- Mac DMG: 설치 구조·임시 서명·리소스 무결성 검사 통과
- Windows x64 폴더와 전체 폴더 ZIP: 새 0.0.11 소스로 생성, 배포 리소스 검사 통과
- Windows 실기 검사와 Setup EXE 생성: GitHub Actions의 Windows 배포 검사에서 수행

## 다운로드

- Mac: `YourSQL-Mac-arm64.dmg`
- Windows: `YourSQL-Setup-x64.exe` 또는 폴더형 `YourSQL-Windows-x64.zip`

기존 학습 기록과 개인 테마는 유지됩니다. MySQL Server 8.0 또는 8.4는 별도 설치가 필요합니다.
