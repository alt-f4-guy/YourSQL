# YourSQL 0.0.10

- SQL 작성 300문제와 빈칸 240문제의 설명을 검토했습니다. 모호한 날짜·집계 조건, 실제 결과와 맞지 않는 제목, 어색한 문장을 교정했습니다.
- 빈칸 지시문이 제목과 본문에 중복되던 부분을 제거했습니다. 문제 ID·정답 SQL·채점 조건과 기존 학습 기록은 유지합니다.
- 빈칸·SQL 복습에서 다시 틀리면, 정답으로 마무리한 다음 날 다시 복습합니다. 틀린 채 중단한 문제도 다음 날 미완료 복습으로 남습니다.
- 기본 3회 복습과 오답 회차당 1회 추가 규칙은 유지합니다. 오답 없이 마친 회차는 기존 3일·7일 간격을 적용합니다.
- 복습 정답 제출 후에도 다음 복습 날짜를 안내합니다. 중복 제출·재시작·연말 날짜 변경을 검사했습니다.

## 알려진 Windows 제한

MySQL 준비 중 앱을 종료하고 곧바로 다시 실행하면 전용 서버가 남아 연결에 실패할 수 있습니다. 이번 배포는 이 기존 제한을 수용하며, 전체 화면·설치·재설치·제거 검사를 생략합니다. 준비가 끝나 ‘로컬 전용’ 상태가 된 뒤 종료하세요.

## 다운로드

- Mac: `YourSQL-Mac-arm64.dmg`
- Windows: `YourSQL-Setup-x64.exe` 또는 폴더형 `YourSQL-Windows-x64.zip`

기존 학습 기록과 개인 테마는 유지됩니다. MySQL Server 8.0 또는 8.4는 별도 설치가 필요합니다.
