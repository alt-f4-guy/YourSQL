# YourSQL 0.0.4

## 변경 사항

- 빈칸 정답에서 `required=1`과 `required = 1`처럼 연산자·구두점 주변 공백이 다른 SQL을 동일하게 판정합니다.
- 빈칸 문제에 참조 테이블의 열 이름·자료형·설명과 접어서 볼 수 있는 예제 데이터를 표시합니다.
- 개념 학습에 전체·단원별 진행 막대와 완료 문제 수·퍼센트를 표시합니다.
- 개념 목록에서 직접 푼 문제도 일별 누적에 반영하며 같은 날 중복 제출은 중복 합산하지 않습니다.

기존 학습 기록과 개인 테마는 보존합니다. 과거에 누적에서 빠졌던 자유 학습 내역을 소급 복원하지는 않습니다.

## 배포 및 검증

- Apple Silicon Mac: `YourSQL-Mac-arm64.zip`
- Windows x64: `YourSQL-Windows-x64.zip`

두 운영체제의 앱은 같은 소스로 빌드합니다. 압축을 푼 폴더 전체를 유지하세요. MySQL Server는 별도로 필요합니다.
핵심 테스트와 Mac 실제 앱 화면·학습·채점·재시작 검사, 배포 테마와 Mac 임시 서명 검사를 수행합니다. Windows 실기 실행·업데이트 검사는 미수행입니다.
Mac 앱은 임시 서명이며 Apple Developer ID 서명·공증은 아닙니다.
