# YourSQL 0.0.7

- Windows 설치 시 기존 YourSQL에 정상 종료를 요청하고, 10초 내 종료되지 않으면 해당 설치 경로의 프로세스를 강제 종료한 뒤 업데이트합니다. 강제 종료 시 저장되지 않은 입력은 유실될 수 있습니다. 종료 실패 시 파일 교체를 중단합니다.
- 오늘의 학습에서 정답 제출 후 Mac `⌘ + Option + Enter`, Windows `Ctrl + Alt + Enter`로 다음 미완료 쿼리로 이동합니다.
- 다음 쿼리 버튼에 단축키를 표시하고 이동 후 편집기에 입력 초점을 유지합니다.
- 기존 실행·정답 제출 단축키를 유지하며, 초안 저장 실패·실행 중·대화상자 표시 중에는 이동하지 않습니다.
