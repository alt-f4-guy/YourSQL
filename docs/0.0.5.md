# YourSQL 0.0.5

- Windows 쿼리 실행·제출 시 학습 계정의 `Access denied` 오류를 유발하던 인증 방식을 수정했습니다. 로컬 파이프 연결에서 RSA 비밀번호 교환을 사용합니다.
- Mac 배포를 DMG로 변경하고 테마를 사용자 데이터 폴더에 저장하여 격리 실행 경로에서도 앱이 열리도록 수정했습니다.
- Windows에서 업데이트 보조 프로그램이 명령 실행 없이 종료되던 실행 옵션을 수정했습니다.
- 업데이트 보조 프로그램을 종료한 뒤 임시 폴더를 정리하고, 정리 중 발생한 EPERM이 최초 오류를 덮어쓰지 않도록 수정했습니다.
- 업데이트 실패 원인과 보조 프로그램 출력을 사용자 데이터 폴더의 `update-error.txt`, `update-helper-output.txt`에 보존합니다.
- Windows 업데이트에서 대괄호가 포함된 경로도 정확하게 실행합니다.

기존 0.0.2에서 자동 업데이트가 실패하면 앱을 종료하고 새 Windows ZIP을 별도 폴더에 전체 압축 해제한 뒤 `YourSQL.exe`를 실행하세요. 학습 기록은 `%APPDATA%/YourSQL`에 있어 유지됩니다.

Mac과 Windows는 동일한 소스를 사용합니다. MySQL Server 8.0 이상이 필요합니다.
