# YourSQL 0.0.9

- Mac·Windows에서 MySQL 서버 실행 파일을 찾지 못하면 공식 MySQL 8.4 설치 페이지를 실행당 한 번 자동으로 엽니다. 설치 안내 버튼과 재연결을 제공하고 일반 서버 오류와 구분합니다.
- 오늘의 학습·추가 학습·오늘의 빈칸 이어하기에서 해당 단원의 개념 설명창을 먼저 표시합니다. ‘빈칸 문제 풀기’를 누르면 문제로 이동합니다.
- 오늘의 6+2 학습을 완료하면 하루 한 번 복습 알림을 표시합니다. 오늘 복습이 있으면 바로 시작할 수 있고, 예정된 복습만 있으면 다음 날짜를 안내합니다. 추가 학습·재시작 때 같은 날 다시 표시하지 않습니다.
- 빈칸·SQL 오답 직후 첫 복습 날짜 또는 진행 중인 복습 일정을 안내합니다. SQL 복습 초안은 같은 예정일의 회차에서만 복원하며 다음 회차에는 빈 편집기로 시작합니다.
- 풀이 중 틀린 문제만 복습합니다. 기본 3회이며 복습 중 오답이 있으면 그 회차에서 한 번만 예정 횟수를 1회 추가합니다.
- 첫 복습은 오답 다음 날, 이후 첫 복습 완료일부터 3일 뒤, 두 번째 완료일부터 7일 뒤입니다. 추가 회차는 직전 복습 완료일부터 7일 뒤입니다.
- 정답까지 고쳐 풀면 한 회차가 완료됩니다. 당일 중복 제출·재시작·해설 열람으로 회차가 늘거나 일정이 당겨지지 않습니다. 복습 종료 뒤 새로 틀리면 기본 3회로 다시 시작합니다.
- SQL 답안 오류는 복습에 반영하고 서버 준비·연결 오류는 제외합니다. 기존 진도는 보존하며 확인 가능한 과거 오답만 이관합니다. 빈칸 문제의 과거 오답 후 정답 이력은 복원할 수 없습니다.
- 기본 라이트 테마의 안내·링크·버튼 대비를 보정하고 버전·보조 제목의 글자를 최소 11px로 조정합니다. 기존 사용자 테마 파일은 자동으로 덮어쓰지 않습니다.
