# YourSQL 0.0.3

## 변경 사항

- 일일 학습과 추가 학습을 빈칸 6문제 + 쿼리 작성 2문제로 확장했습니다.
- 이전 3+1 배정의 정답 기록을 보존하면서 오늘 배정을 새 구성으로 확장합니다. 과거 날짜의 학습 기록은 유지합니다.
- 상단 ‘학습 기록’ 메뉴에 연간 히트맵을 추가했습니다. 날짜별 완료 수, 빈칸·쿼리 내역, 연도 이동과 방향키 탐색을 지원합니다.
- 홈의 중복 목록과 달력 토글을 제거하고 다음 학습 행동을 강조했습니다.
- 완료 후 복습 안내, 개념 목록의 상태 표시, 글자 크기와 간격을 정리했습니다.

테마 정의와 개인 학습 기록은 유지됩니다. 임의의 마지막 방문 위치 및 미제출 빈칸 답안의 영구 복원은 포함하지 않습니다.

## 배포

배포 테마는 macOS 라이트·macOS 다크 두 종류만 포함합니다. 개인 제작 테마는 배포 ZIP에서 제외하며, 이미 설치된 사용자 테마는 자동 업데이트 시 그대로 보존됩니다.

- Apple Silicon Mac: `YourSQL-Mac-arm64.zip`
- Windows x64: `YourSQL-Windows-x64.zip`

압축을 푼 폴더 전체를 유지하세요. 두 운영체제 모두 별도 MySQL Server가 필요합니다. Windows 실기 실행·업데이트 검사는 미수행입니다.

## Mac 임시 서명 재배포

Mac 앱에 무료 임시 서명(ad-hoc)을 적용하고, ZIP 압축 해제 후 중첩 코드와 리소스의 서명을 검사합니다. Apple Developer ID 서명·공증은 아니므로 다운로드한 앱에 보안 경고가 표시될 수 있습니다. 출처를 확인한 뒤 macOS의 ‘개인정보 보호 및 보안’에서 해당 앱의 실행을 승인해야 할 수 있습니다. 보안 기능을 전역으로 해제하지 않습니다.

기존 v0.0.3 파일을 받았다면 새 ZIP을 다시 내려받으세요. 같은 버전 재배포이므로 자동 업데이트 알림은 발생하지 않습니다. 개인 학습 기록과 로컬 테마는 삭제하지 마세요.
