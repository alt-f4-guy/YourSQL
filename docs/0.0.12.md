# YourSQL 0.0.12

- **오후 8시 학습 알림:** 설정에서 켜면 오늘 목표 사이클이 남았을 때 하루 한 번 알림을 요청합니다. 기본은 꺼짐이며, 앱을 닫아도 OS 예약이 검사합니다. 절전·로그인으로 놓친 경우 당일 20시~22시 사이에만 다시 확인합니다.
- **필수 쿼리를 포함한 완료 판정:** 빈칸을 모두 풀어도 필수 쿼리가 남으면 전체 완료로 표시하지 않습니다. 다음 날 같은 단원을 새 6+2로 배정하고 오늘 완료 수는 0부터 시작합니다. 기존 초안과 과거 학습 기록은 보존합니다.
- **기록 백업과 복구:** 검증된 직전 정상본을 백업하고, 손상 원본은 별도로 보존한 뒤 복원합니다. 복구할 수 없으면 기록을 초기화하지 않고 복구 안내·기록 폴더 열기·재시도를 제공합니다. 일부 오답 파일의 손상은 정상 기록을 막지 않습니다.
- **알림 설정 복구 보호:** 백업 복원 시 알림을 끄고 그날 자동 알림을 보류합니다. 사용자가 다시 켜도 같은 날 중복 요청하지 않습니다.
- **종료 안정성:** SQL 실행이나 초안 저장 실패로 종료를 보류해도 알림 감시는 유지됩니다. 실제 종료가 확정된 뒤 감시와 전용 MySQL을 정리합니다. MySQL 시작 중 종료해도 서버가 남지 않도록 연결 대기와 종료를 순서대로 처리합니다.
- **Windows 제거:** 대상 설치 경로만 정상 종료·정리하고, 무응답 시 선택을 제공합니다. 무인 강제 제거에는 `/FORCE`가 필요합니다. 예약 삭제·파일 삭제 실패를 성공으로 표시하지 않고 재시도 정보를 보존합니다.

## 검증

- Mac 핵심 자동 검사 96개, 기존 학습·설정·채점·재시작 화면 검사 통과.
- 손상 파일 복구 화면, 알림 설정·초안 보존, 종료 보류 후 resume 감시 검사 통과.
- Mac 배포 앱의 창 없는 알림 실행과 전용 테스트 LaunchAgent 등록·조회·해제 통과.
- Mac DMG와 앱은 기존 임시(ad-hoc) 서명을 유지합니다. 정식 서명·공증은 추가하지 않았습니다.
- [Windows 전체 CI 검사](https://github.com/alt-f4-guy/YourSQL/actions/runs/35715995797) 통과: Windows Server 2025 x64에서 핵심 96개, 실제 MySQL 300문제·1200회 실행, 소스·배포·설치 앱 화면, 알림·복구, 설치·재설치·제거와 실패 후 재시도, 새 전체 폴더 ZIP을 확인했습니다. 예약·등록 삭제 권한 오류는 API 오류 주입으로 검사했습니다.

실제 OS 알림 배너, 앱 종료 후 알림 클릭, 절전·업데이트 후 알림 권한 유지에는 별도 데스크톱 실기 확인이 남아 있습니다. OS 요청 성공 이벤트는 실제 배너 표시를 보장하지 않습니다.

## 다운로드

- Mac arm64: `YourSQL-Mac-arm64.dmg`
- Windows x64: `YourSQL-Setup-x64.exe` 또는 `YourSQL-Windows-x64.zip`

Windows ZIP은 새 전체 폴더의 파일 목록·SHA-256을 확인합니다. ZIP은 전체 폴더를 풀고 `YourSQL.exe`로 실행하세요. 학습 기록과 개인 테마는 유지됩니다. MySQL Server 8.0 또는 8.4는 별도 설치가 필요합니다.
