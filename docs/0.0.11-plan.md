# YourSQL 0.0.11 업데이트 계획

작성일: 2026-09-16
상태: 구현 및 Mac 검증 완료 — Windows 배포 검사 진행 전

## 목표

1사이클을 **빈칸 6개 + 쿼리 작성 2개**로 유지하면서, 사용자가 하루 학습량을 사이클 단위로 조절할 수 있게 합니다.

현재는 추가 사이클을 이어서 학습할 수 있지만 첫 1사이클을 마치면 하루 목표 달성으로 처리됩니다. 다음 버전에서는 사용자가 설정한 사이클 수를 기준으로 하루 목표 달성 여부를 계산합니다.

## 1. 하루 학습량 설정

- 설정 화면에 ‘하루 목표 사이클’을 추가합니다.
- 1 이상의 정수 단위로 조절하며 기본값은 기존과 같은 1사이클입니다.
- 선택한 사이클 수에 해당하는 빈칸·쿼리 문제 수를 함께 표시합니다.
- 잘못된 값은 저장하지 않고 입력 범위를 안내합니다.

| 하루 목표 | 빈칸 | 쿼리 작성 | 총 문제 수 |
| --- | --- | --- | --- |
| 1사이클 | 6개 | 2개 | 8개 |
| 2사이클 | 12개 | 4개 | 16개 |
| 3사이클 | 18개 | 6개 | 24개 |

표시 예: `3사이클 · 빈칸 18개 + 쿼리 6개`

## 2. 사이클을 이어가는 학습 흐름

- 기존의 ‘개념 설명 → 빈칸 6개 → 쿼리 2개’ 순서를 유지합니다.
- 한 사이클을 마쳐도 하루 목표가 남아 있으면 ‘다음 사이클 시작’을 표시합니다.
- 다음 사이클은 사용자가 버튼을 눌렀을 때 시작합니다.
- 설정한 사이클을 모두 마치면 ‘오늘 목표 달성’으로 표시합니다.
- 목표 달성 후에는 기존처럼 ‘추가 학습하기’로 계속 진행합니다.
- 사이클 이동은 기존 단원 배정 순서와 중복 클릭 방지 동작을 유지합니다.

## 3. 오늘의 진도 표시

하루 전체 목표와 현재 사이클의 진행 상황을 구분합니다.

- 하루 진도: `오늘 목표 1 / 3사이클 완료`
- 현재 사이클 진도: `현재 사이클 4 / 8문제`
- 현재 사이클 상세: `빈칸 4 / 6 · 쿼리 0 / 2`
- 목표를 넘겨 학습한 경우: `오늘 목표 3 / 3사이클 달성 · 추가 1사이클 완료`

사이클 완료는 해당 사이클에 배정된 빈칸과 쿼리를 모두 완료했는지로 판단합니다. 자유 연습이나 복습을 포함한 하루 총 문제 수를 단순히 8로 나누어 계산하지 않습니다. 하루 목표의 진도 표시는 목표치까지만 채우고 초과 학습은 별도로 표시합니다.

## 4. 설정 변경과 기록 보존

다음 정책을 권장안으로 계획합니다.

- 변경한 목표는 오늘부터 적용하고 이후 날짜에도 유지합니다.
- 목표를 바꿔도 완료한 사이클, 진행 중인 배정, 답안과 SQL 초안은 보존합니다.
- 목표를 높이면 오늘의 상태가 ‘목표 달성’에서 ‘진행 중’으로 바뀔 수 있습니다.
- 목표를 낮추면 이미 완료한 사이클 수에 따라 즉시 달성 처리합니다.
- 설정 화면에 ‘변경한 목표는 오늘부터 적용됩니다’를 안내합니다.
- 과거 날짜는 당시 목표와 달성 여부를 유지하며 현재 설정으로 다시 계산하지 않습니다.
- 기존 사용자에게는 기본 목표 1사이클을 적용하고, 구형 학습 구성으로 남은 과거 기록도 기존 달성 판정을 보존합니다.
- 재실행 후에도 목표와 사이클 진행 상황을 복원합니다.
- 날짜가 바뀌면 설정된 목표로 새 날짜를 시작하며 전날 부족한 학습량을 자동으로 더하지 않습니다.

## 5. 달력·복습 알림·과정 종료

### 달력과 목표 달성일

- 날짜별로 저장한 목표와 완료 사이클 수를 기준으로 달성 여부를 표시합니다.
- 날짜 상세에 해당 날짜의 목표와 완료 사이클 수를 표시합니다.
- 기존의 빈칸·쿼리 완료 수 집계를 보존합니다.
- 오늘의 목표 변경은 오늘의 달성 여부와 이를 포함하는 달성일 집계에만 반영합니다.
- 구형 기록에서 확인할 수 없는 사이클 상세는 임의로 만들어 표시하지 않습니다.

### 복습 알림

- 첫 사이클 완료가 아니라 하루 목표 전체의 미달성 → 달성 전환을 기준으로 알립니다.
- 목표를 낮춰 달성 상태가 된 경우에도 같은 기준을 적용합니다.
- 같은 날 목표 변경이나 추가 학습으로 달성 상태가 다시 발생해도 알림은 하루 한 번만 표시합니다.
- 이미 달성한 상태에서 앱을 실행하면 알림을 다시 표시하지 않습니다.
- 기존 복습 간격과 오답 처리 규칙은 유지합니다.

### 전체 과정 종료

- 마지막 단원까지 끝나 목표량을 채울 문제가 부족하면 ‘전체 과정 완료’를 별도로 안내합니다.
- 실제 완료한 사이클 수를 그대로 표시하고 미달한 목표를 달성했다고 기록하지 않습니다.
- 목표를 채우기 위해 문제를 자동 반복하거나 새 사이클을 계속 배정하지 않습니다.
- 이후에는 복습과 단원별 다시 풀기로 안내합니다.

## 8. Mac·Windows 배포 계획

- 기능은 공통 소스에서 구현하고 Mac과 Windows에 함께 적용합니다.
- `npm run package`로 Mac arm64와 Windows x64 산출물을 같은 버전으로 만듭니다.
- Windows 배포 폴더 전체를 새로 압축해 `dist/YourSQL-Windows-x64.zip`을 갱신합니다.
- Windows 실기에서는 `npm test`, `npm run test:packaged`, `npm run test:engine`을 검사합니다. 실행하지 못한 검사는 완료 보고에 명시합니다.
- Mac은 앱 종료 후 `dist/YourSQL-darwin-arm64/YourSQL.app`을 프로젝트의 `YourSQL.app`에 복사하고 `npm run test:app`으로 검사합니다.

## 이번 버전의 범위

이번 계획은 **고정된 6+2 구성을 하루에 몇 사이클 학습할지 설정하는 기능**에 집중합니다. 요일별 목표, 사이클 내부 문제 수 조절, 미달 학습량의 자동 이월은 후속 기능으로 남깁니다.
