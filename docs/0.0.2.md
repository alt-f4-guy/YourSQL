# YourSQL 0.0.2

- 일일 학습 완료 후 복습 대상이 있으면 ‘복습 시작’을, 없으면 ‘추가 학습하기’를 강조합니다. 추가 학습은 다음 빈칸 6문제와 쿼리 2문제로 이어집니다.
- 하루에 여러 사이클을 진행하고, 앱을 다시 열어 진행 중인 사이클을 이어갈 수 있습니다.
- 학습 달력에 하루 누적 완료 문제 수와 빈칸·쿼리별 개수를 표시합니다. 추가 사이클을 시작해도 하루 목표 달성은 유지됩니다.
- 공식 Aura 다크 팔레트를 적용하고 SQL 문법색과 주석 가독성을 보완했습니다.

기존 학습 기록과 사용자 테마는 유지됩니다. 자동 업데이트는 기존 외부 테마를 보존하므로 Aura가 없는 설치에서는 새 ZIP의 `theme/aura.json`을 기존 테마 폴더에 추가하면 됩니다.

배포 파일은 `YourSQL-Mac-arm64.zip`과 `YourSQL-Windows-x64.zip`입니다. 두 운영체제 모두 MySQL Server를 별도로 설치해야 합니다.

Windows 실기에서 실행·업데이트 검사는 아직 수행하지 못했습니다.

## 학습 기록

- 홈의 달력 토글을 제거하고 상단에 ‘학습 기록’ 메뉴를 추가했습니다.
- 연간 히트맵은 날짜별 완료 수를 0·1–3·4–7·8–15·16개 이상으로 표시합니다.
- 연도 이동, 날짜별 빈칸·쿼리 완료 내역, 방향키 탐색을 지원합니다. 기존 테마와 학습 기록을 그대로 사용합니다.

## 디자인 정리

- 테마와 색상 정의는 변경하지 않고 홈의 중복 모드 설명·개념 목록을 줄였습니다.
- 학습 달력은 기본 접힘으로 유지하고 개념 목록은 학습 현황에서 접근합니다.
- 완료 수치 크기와 목록 간격을 조정하고 개념 진도에 시작 전·진행 중·완료·복습 필요를 표시합니다.
- 복습 0건과 향후 예정일을 구분하며, 오늘 배정의 재개는 ‘오늘 학습 이어하기’로 표시합니다.
- 임의의 마지막 방문 위치와 미제출 빈칸 답안의 영구 복원은 이번 변경에 포함하지 않습니다.

- 하루 분량을 빈칸 6문제 + 쿼리 작성 2문제로 확대하고, 8문제 진행률과 다음 쿼리 버튼을 표시합니다. 오늘의 기존 배정은 정답을 유지하며 확장하고 이전 날짜의 기록은 보존합니다.
