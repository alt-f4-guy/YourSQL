# YourSQL 0.0.14

- 오늘 복습할 문제가 있어도 첫 학습 버튼은 ‘오늘의 학습 시작’으로 표시합니다.
- 진행 중에는 ‘오늘 학습 이어하기’, 현재 사이클을 완료한 뒤 복습할 문제가 있으면 ‘복습 시작’으로 표시하여 실제 클릭 동작과 일치시켰습니다.
- Mac과 Windows에 같은 수정이 적용됩니다. 학습 기록과 개인 테마는 유지됩니다.

## 검증

- 소스 핵심 자동 검사 96개, 전체 화면 검사, 복습 알림 검사 통과.
- 복습 대기 중 첫 학습·진행 중·사이클 완료 상태의 버튼 문구와 학습 진입을 검사했습니다.
- 교체한 Mac 배포 앱의 화면·학습·MySQL 채점·재시작 및 버튼 문구·복습 알림 검사 통과. DMG 설치 구조·임시 서명·리소스 무결성 검사 통과.
- [Windows 빌드 전용 CI](https://github.com/alt-f4-guy/YourSQL/actions/runs/40431334110) 통과: 핵심 검사, MySQL 연결·복구·정답 채점, Setup 생성, 새 전체 폴더 ZIP 검사 완료. 빌드 소스는 `4c908af`입니다.
- Windows 데스크톱 실기 검사는 요청에 따라 생략했습니다. Windows CI의 화면·설치·제거 검사도 생략했습니다.

## 다운로드

- Mac arm64: `YourSQL-Mac-arm64.dmg`
- Windows x64: `YourSQL-Setup-x64.exe` 또는 `YourSQL-Windows-x64.zip`

Windows ZIP은 전체 폴더를 풀고 `YourSQL.exe`로 실행하세요. MySQL Server 8.0 또는 8.4는 별도 설치가 필요합니다.

정식 서명·공증 부재와 OS 알림 관련 기존 제한은 [0.0.12 검증 기록](0.0.12.md)을 참고하세요.
