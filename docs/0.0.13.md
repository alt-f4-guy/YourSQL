# YourSQL 0.0.13

- SQL 작성 문제의 정렬 기준을 `course_id 오름차순`처럼 각 항목의 실제 방향으로 안내합니다. 복합 정렬도 열마다 오름차순·내림차순을 표시합니다.
- 반복되던 DESC 문법 안내와 불필요한 전체 기간 안내를 제거하고, 결과 열 사이의 간격을 정리했습니다. 총 162개 문제 설명을 다듬었습니다.
- 300개 문제의 정답 SQL, 채점 조건, 식별자는 그대로 유지합니다. 학습 기록과 개인 테마도 유지됩니다.

## 검증

- Mac 핵심 자동 검사 96개와 교체한 `YourSQL.app`의 화면·설정·학습·복습·MySQL 채점·재시작 검사 통과.
- Mac DMG 설치 구조, 임시(ad-hoc) 서명과 리소스 무결성 검사 통과.
- Mac 앱에 포함된 버전과 두 문제 팩이 0.0.13 소스와 일치함을 확인.
- [Windows 전체 CI](https://github.com/alt-f4-guy/YourSQL/actions/runs/40181885503) 통과: 핵심 검사, 실제 MySQL 연결·복구·정답 채점, 소스·배포 앱 학습·알림·기록 복구, 설치·재설치·제거, 새 전체 폴더 ZIP 검사를 완료했습니다. 빌드 소스는 `9419674`입니다.
- Windows 검사는 GitHub Actions의 Windows 실행 환경에서 수행했습니다. 별도 사용자 데스크톱 실기 검사는 수행하지 않았습니다.

## 기존 제한 사항

이번 버전은 문제 설명 개선입니다. 이전 버전에서 공지한 정식 서명·공증 부재와 실제 OS 알림 배너·클릭·절전 후 동작의 데스크톱 실기 미검증 사항은 그대로 유지합니다. 자세한 내용은 [0.0.12 검증 기록](0.0.12.md)을 참고하세요.

## 다운로드

- Mac arm64: `YourSQL-Mac-arm64.dmg`
- Windows x64: `YourSQL-Setup-x64.exe` 또는 `YourSQL-Windows-x64.zip`

Windows ZIP은 전체 폴더를 풀고 `YourSQL.exe`로 실행하세요. MySQL Server 8.0 또는 8.4는 별도 설치가 필요합니다.
