# YourSQL 0.0.6

- Windows 배포를 ZIP에서 현재 사용자용 설치 마법사로 변경했습니다.
- Mac은 Applications로 드래그하는 DMG 배포를 유지합니다.
- 업데이트는 앱 파일을 직접 교체하지 않고 공식 릴리스의 운영체제용 설치 페이지를 엽니다.
- Windows 사용자 테마를 `%APPDATA%/YourSQL/theme/`으로 옮겨 앱 업그레이드와 제거 후에도 유지합니다.

0.0.5의 앱 내부 updater는 ZIP만 인식하므로 0.0.6은 이 릴리스 페이지에서 운영체제용 파일을 한 번 직접 내려받아 설치해야 합니다. Windows 0.0.5 폴더에 개인 테마가 있다면 JSON 파일을 `%APPDATA%/YourSQL/theme/`으로 한 번 복사하세요.

학습 기록은 Mac의 `~/Library/Application Support/YourSQL/`, Windows의 `%APPDATA%/YourSQL/`에 그대로 유지됩니다. Mac 앱과 Windows 설치 파일은 아직 상용 인증서로 서명되지 않았으므로 운영체제 보안 경고가 표시될 수 있습니다.
