[Windows 전체 CI 실행](https://github.com/alt-f4-guy/YourSQL/actions/runs/35715995797)은 모든 단계가 통과했다.

최종 패키지·ZIP·앱 사본 검증 결과는 [통합 배포 대기 기록](pending-release.md)에 누적한다. Windows CI의 `build_only`는 검사를 생략한 로컬 산출물이며 배포 검증 완료를 뜻하지 않는다.

구현 참고: [Microsoft TaskFolder.GetTask](https://learn.microsoft.com/en-us/windows/win32/taskschd/taskfolder-gettask), [NSIS 제거 프로그램 실행·삭제 규칙](https://nsis.sourceforge.io/Docs/Chapter4.html).

예약과 레지스트리 삭제의 접근 거부 ACL은 관리자 CI에서 재현되지 않아 API 경계에서 오류를 주입해 실패 처리·복원·재시도 검사를 통과했다. 실제 접근 제어 정책의 검증으로 해석하지 않는다. NSIS 등록 삭제 오류는 배포 코드에 테스트 옵션을 추가하지 않고, 원본 제거 코드에서 해당 호출만 바꾼 검사 전용 실행 파일로 검사한다.
