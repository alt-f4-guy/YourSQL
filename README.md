# YourSQL 0.0.8

매일 짧게 SQL을 연습하고, 틀린 문제를 다시 풀며 학습 기록을 쌓는 개인용 데스크톱 앱입니다. Mac과 Windows에서 같은 학습 기능을 제공합니다.

**0.0.5의 앱 내부 updater는 ZIP만 인식하므로 0.0.8은 이 릴리스 페이지에서 운영체제용 파일을 한 번 직접 내려받아 설치해야 합니다.**

## 주요 기능

- **오늘의 학습:** 빈칸 6문제와 SQL 작성 2문제로 구성한 하루 루틴
- **추가 학습:** 하루 루틴 완료 후 같은 구성으로 계속 학습
- **단계별 연습:** 5단계·40단원·빈칸 240문제와 SQL 작성 300문제
- **실행과 채점:** 로컬 MySQL에서 쿼리를 실행하고 공개 예제·숨겨진 데이터로 정답 확인
- **복습과 기록:** 오답 기록, 간격 복습, 연간 학습 히트맵, 연속 학습일수
- **다음 쿼리 단축키:** 오늘의 학습과 복습에서 정답 제출 후 Mac `⌘ + Option + Enter`, Windows `Ctrl + Alt + Enter`로 다음 쿼리 이동
- **풀이 도구:** SQL 문법 색상, 초안 저장, 단계별 힌트와 해설
- **화면 설정:** 테마 선택과 외부 테마 파일 관리
- **앱 업데이트:** 실행 시 새 버전 알림과 공식 릴리스 다운로드 페이지 안내

학습 기록은 각 컴퓨터에 저장됩니다. 계정 가입과 클라우드 동기화 기능은 없으며, PC와 노트북의 기록은 자동으로 합쳐지지 않습니다. MySQL 설치 후 학습은 인터넷 없이 할 수 있고, 업데이트 확인·다운로드에는 인터넷이 필요합니다.

## 다운로드

이 GitHub 저장소의 **Releases → 최신 정식 버전 → Assets**에서 운영체제에 맞는 파일을 받으세요.

| 운영체제 | 다운로드 파일 | 실행 파일 |
|---|---|---|
| Apple Silicon Mac · arm64 | `YourSQL-Mac-arm64.dmg` | `YourSQL.app` |
| Windows · x64 | `YourSQL-Setup-x64.exe` | 설치 마법사 |

현재 Intel Mac과 Windows ARM 전용 빌드는 제공하지 않습니다. **Code → Download ZIP**이나 릴리스의 **Source code**는 개발용 소스이며, 실행 앱이 아닙니다.

### 공통 준비: MySQL 서버

두 운영체제 모두 **MySQL Server 8.0 또는 8.4**를 별도로 설치해야 합니다. 앱 설치 파일에 MySQL 서버는 포함되어 있지 않습니다. [MySQL 공식 다운로드](https://dev.mysql.com/downloads/mysql/)에서 버전 선택을 **8.4 LTS 또는 8.0**으로 바꾸고 해당 운영체제용 서버를 설치하세요.

YourSQL은 설치된 서버 실행 파일로 **앱 전용 데이터베이스**를 구동합니다. 기존 MySQL 서비스의 데이터베이스나 접속 비밀번호를 사용하지 않으므로 앱에 개인 DB 계정 정보를 입력할 필요가 없습니다.

### Mac에서 설치·실행

1. `YourSQL-Mac-arm64.dmg`를 내려받아 엽니다.
2. **`YourSQL.app`**을 같은 창의 **`Applications`** 바로가기로 끌어 놓습니다.
3. 응용 프로그램 폴더의 **`YourSQL.app`**을 실행합니다.
4. 처음 실행할 때는 연습용 데이터베이스 초기화가 끝날 때까지 기다립니다.

### Windows에서 설치·실행

1. `YourSQL-Setup-x64.exe`를 내려받아 실행합니다.
2. 설치 마법사를 완료합니다.
3. 시작 메뉴의 **YourSQL**을 실행합니다.
4. 처음 실행할 때는 연습용 데이터베이스 초기화가 끝날 때까지 기다립니다.

### 실행이 되지 않을 때

- **MySQL을 찾지 못함:** MySQL Server가 설치되어 있는지 확인하세요. Windows에서는 기본 설치 폴더와 PATH를, Mac에서는 표준 설치 폴더와 PATH를 확인합니다. 다른 위치에 설치했다면 `YOURSQL_MYSQLD` 환경 변수에 `mysqld` 또는 `mysqld.exe`의 절대 경로를 지정하고 앱을 다시 실행하세요.
- **운영체제 보안 경고:** Mac 앱은 무료 임시 서명(ad-hoc)을 사용하며 Apple Developer ID 서명·공증은 적용하지 않았습니다. Windows 설치 파일도 상용 인증서로 서명되지 않아 SmartScreen 경고가 표시될 수 있습니다. 다운로드한 저장소와 파일을 확인하고 해당 운영체제의 앱 실행 안내를 따르세요. 앱은 보안 설정을 자동으로 해제하지 않습니다.

## 학습 기록과 테마

배포본에는 macOS 라이트·macOS 다크만 포함됩니다. 개인 테마는 로컬 `theme` 폴더에서 별도로 관리합니다.

| 항목 | Mac | Windows |
|---|---|---|
| 학습 기록·앱 설정 | `~/Library/Application Support/YourSQL/` | `%APPDATA%/YourSQL/` |
| 외부 테마 | `~/Library/Application Support/YourSQL/theme/` | `%APPDATA%/YourSQL/theme/` |

0.0.5 Windows 폴더에 개인 테마가 있다면 기존 앱의 `theme` 폴더에서 JSON 파일을 `%APPDATA%/YourSQL/theme/`으로 한 번 복사하세요.

백업할 때는 **앱을 종료한 뒤 학습 기록 폴더 전체**를 복사하세요. 테마를 수정했다면 외부 `theme` 폴더도 따로 백업하세요. 앱 업그레이드와 제거 후에도 학습 기록과 사용자 테마는 유지됩니다.

## 앱 내부 업데이트

1. 앱 실행 시 새 정식 버전이 있으면 **업데이트가 있습니다** 팝업이 표시됩니다. 설정의 **업데이트 확인**으로 직접 확인할 수도 있습니다.
2. **다운로드 페이지 열기**를 누릅니다.
3. 앱을 종료합니다.
4. 운영체제에 맞는 DMG 또는 Setup EXE를 내려받아 설치합니다.

## 소스로 실행하기

소스 개발에는 Node.js 22.12 이상과 npm이 필요합니다. 쿼리 실행에는 별도의 MySQL 서버 실행 파일도 필요합니다.

```sh
# 저장소 폴더에서 의존성을 설치하고 개발 앱을 실행합니다.
npm ci
npm start
```
