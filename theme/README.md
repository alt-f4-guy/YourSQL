# 테마 파일 관리

앱 상단의 **테마 폴더** 버튼으로 현재 사용하는 폴더를 엽니다.
개발 앱은 프로젝트의 `theme` 폴더, 배포 앱은 `.app` 바로 옆의 `theme` 폴더를 읽습니다.
앱을 옮길 때는 `theme` 폴더도 함께 옮겨 주세요.

테마 하나를 JSON 파일 하나로 저장합니다. 기존 JSON을 복사하여 고유한 `id`, 표시 이름 `name`,
`scheme`(`light` 또는 `dark`), `colors`를 수정하면 됩니다. 색상은 `#RRGGBB` 형식이며
기존 파일의 기본 색상 16개와 문법 색상 5개를 모두 유지하세요.
문법 색상은 `sql-keyword`, `sql-string`, `sql-number`, `sql-comment`, `sql-function`이며
각각 키워드·문자열·숫자·주석·함수 이름에 적용됩니다. 문법 색상이 없는 구형 파일은
기존 강조색·성공색·오류색·보조 글자색·본문색에서 자동 보완합니다. 파일 이름은 자유롭게 정할 수 있습니다.
하위 폴더나 심볼릭 링크는 읽지 않으며 JSON 파일 크기는 64KB 이하여야 합니다.

파일을 추가·수정·삭제하면 실행 중인 앱에 자동 반영됩니다. 사용 중인 테마의 색상을 수정하면
화면 색상도 바뀝니다. 잘못된 JSON이나 중복된 `id`는 제외하고 앱에 오류를 표시합니다.
`macOS 라이트`와 `macOS 다크`를 목록 맨 앞에 표시하며, 저장된 선택이 없으면 라이트를 사용합니다.

**테마 삭제**는 확인 후 해당 JSON 파일을 실제로 삭제합니다. 앱에서는 마지막 테마 하나를
남기지만, 폴더에서 모든 파일을 직접 삭제할 수도 있습니다. 이때 기본 라이트 화면으로 표시하며
테마 파일을 자동 재생성하지 않습니다. 재실행과 재빌드도 삭제한 테마를 복원하지 않습니다.
이전 버전에서 숨겼던 테마는 첫 실행 시 실제 파일 삭제로 이관합니다(마지막 테마는 보존).
